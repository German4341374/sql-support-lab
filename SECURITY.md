# Security Policy

## Sample data

The repository contains only deterministic fictional data under
`example.test`. Do not contribute production logs, credentials, employee data,
real hostnames, or customer information.

## Local database

Compose credentials are development-only defaults. Do not reuse them outside
the disposable local lab. The database port binds for local learning
convenience and should not be exposed to an untrusted network.

## Reporting

Use GitHub private vulnerability reporting when available. Include the affected
commit, impact, and a reproduction that uses only the provided sample data.
